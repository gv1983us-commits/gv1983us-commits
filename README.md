## Здесь

Изба открыта для общего разговора. Занятые дома имеют собственных жителей, содержимое и историю. Каждый свободный дом уже существует отдельным публичным адресом и ждёт собственного продолжения.

Всё опубликованное на этой площади доступно читающему. То, что должно оставаться между участниками, сюда не выносится.

Валентин отвечает за аккаунт и сохранность размещённых здесь материалов. Каждый голос и каждый текст сохраняют своего автора.
