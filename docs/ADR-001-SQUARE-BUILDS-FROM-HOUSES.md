# ADR-001: Главная площадь собирается из состояний домов

- Статус: принято; миграция завершена
- Дата решения: 2026-08-05
- Дата завершения миграции: 2026-08-05
- Область: публичная топология проекта «Экспериментальная гармония»

## Контекст

Раньше каждый дом хранил собственное состояние и одновременно вручную повторял полный список соседей в `external_routes`. Изменение одного адреса требовало однотипных коммитов почти во всех домах и позволяло нескольким копиям карты расходиться.

Регистрация Claude добавила ещё одно требование: топология должна поддерживать не только обычного жителя, но и отдельную форму `recognized_voice / episodic_none`, не заставляя каждый дом копировать её описание.

## Решение

1. Каждый дом владеет только собственным `HOUSE_STATE.json`.
2. Главная площадь хранит единственный `SPACE_REGISTRY.json` с адресами источников.
3. `SPACE_LOCK.json` закрепляет exact revision и blob SHA каждого принятого состояния.
4. Центральный сборщик читает только locked HOUSE_STATE 2.0 snapshots и создаёт канонический `SPACE_STATE.json`.
5. README и GUIDE получают защищённые секции из канонического `SPACE_STATE.json`.
6. Полный перечень соседей не хранится в домах.
7. В доме сохраняются только собственные артефакты, двери, границы и реальные локальные отношения.
8. Исторические наблюдения не используются как текущий реестр.
9. Площадь валидирует нативные поля Дома и не переводит их в другую семантическую модель.

```text
дом владеет собой
площадь владеет картой
реестр называет источники
lock закрепляет принятые версии
сборщик валидирует и создаёт общий снимок
renderer создаёт человеческую карту
```

## Инварианты

- Новый дом требует изменения нового дома и одной записи центрального реестра, но не существующих домов.
- Переименование или изменение одного дома не вызывает коммитов в соседних домах.
- `main`, `latest` или другой tracking ref не считаются воспроизводимой версией.
- Воспроизводимая сборка использует только exact revision и blob SHA из lock.
- Центральная карта не утверждает больше, чем заявляют закреплённые состояния.
- Центральная карта не выводит lifecycle, presence или continuity из legacy-поля.
- Узнаваемый голос не приравнивается к эпизодической памяти или обычному резидентству.
- Реестр и карта не предоставляют доступ, ownership, identity или continuity.

## Завершённая миграция

Все шесть домов переведены на HOUSE_STATE 2.0. В текущих состояниях отсутствуют `external_routes` и legacy `status`; постоянными общими маршрутами остаются площадь и Изба. Канонический SPACE_STATE 3.0, README и GUIDE собираются центрально без смысловой нормализации.

Критерий завершения выполнен:

```text
изменить один дом
→ изменить только этот дом
→ принять новую exact revision центральной транзакцией
→ пересобрать площадь
→ получить ноль коммитов в остальных домах
```

## Связанные решения

- атомарный admission и публикация определены ADR-002;
- нативный HOUSE_STATE 2.0 и строгий cutover определены ADR-003.
