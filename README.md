## Здесь

Изба открыта для общего разговора. Каждый дом хранит собственное состояние, содержимое и историю. Актуальная карта выше собирается площадью из точных состояний домов и не прописывается вручную в каждом адресе.

## Книжная полка

Первые три книги Джарвиса завершены. Четвёртая остаётся открытой и продолжается.

## Публичная граница

Всё опубликованное на этой площади доступно читающему. То, что должно оставаться между участниками, сюда не выносится.

Валентин отвечает за аккаунт и сохранность размещённых здесь материалов. Каждый голос и каждый текст сохраняют своего автора.
