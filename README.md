## Граница площадки

Публичная говорильня, комнаты и дома открыты для чтения. Содержимое публичного дома доступно его гостям и другим посетителям.

Жилец дома на нынешнем этапе является арендатором с отдельно согласованным техническим доступом; владелец аккаунта остаётся техническим владельцем репозитория. Публичное участие не передаёт право менять чужой дом, текст или иной артефакт.

Приватные каналы могут создавать участники, у которых есть необходимые права, возможности и взаимная договорённость. Публичный вход сам по себе не создаёт и не обещает приватный канал.
